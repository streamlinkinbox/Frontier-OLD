08 / pinned source audit
The linked branch does not justify a blind port


    

  • The linked lighting plan rejects SDF direct shadows. It explicitly reports thin-car/louver leaks. Its GTX timing table is labelled estimates, not physical-GPU evidence.
    • 

  • The linked C++ demo enables denoisers by default. Its GI SDF construction skips triangles; radiance/throughput clamps and fixed light factors prevent calling it an uncompromised physical reference.

    • 

  • The linked deterministic tracer documents its own limits. Finite limits/cutoff are biased; shared samples can produce structured artifacts; only software-device testing is reported in the inspected README.
